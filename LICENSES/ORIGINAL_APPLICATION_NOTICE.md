# Licensing status

The original user-space portions of this repository have not been released
under an open-source license. No public permission to copy, redistribute or
modify those portions is granted at this time.

The imported Linux kernel source under `driver/source/` retains the SPDX
license identifiers and copyright notices present in those files and remains
subject to the applicable Linux kernel licensing terms. A copy of the kernel's
top-level notice is stored at `driver/COPYING`.

Before making this repository public, the project owner must select and add an
explicit license for the original application, documentation and test code.
