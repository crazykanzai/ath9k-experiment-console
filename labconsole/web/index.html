使用说明

实验工作台

这一版可以配置平台、封存方案、演练停止与故障流程，并读取已有单发结果生成报告。所有操作都在本机完成。

本版本不会连接节点。 演练阶段采用压缩时间，数值指标全部为NA，正式有效窗口始终为0。真实SSH、配置恢复和采集门禁尚未由本界面现场验收。
1

配置与检查

导入平台档案。IP、账号和远端目录成为配置；密码不写入档案。

2

方案与演练

查看每一轮发送集合和CW。计划封存后，演练按顺序运行。

3

读取已有数据

显式指定已归档的单发汇总文件，保留NA与完整失败包。

    AP 接收速率 · Mbps
    AP station dump字节差分估算，包含其计数范围的流量；不是正式iperf应用吞吐。
    区间成功样本 HoL · ms
    累计量差分，按TX完成回调归属采样区间；不等同最终完整服务包HoL，不伪造逐包精度。
    区间逐次 ACK 成功代理 · %
    Basic ABI2成功路径代理；含未核准终态失败、RTS、无尝试或重置时NA。非精确碰撞概率。
    实际 BE CWmin 读回
    硬件读回阶梯线。竖虚线为发现变化的采样时刻，实际变化发生在相邻读回之间；请求事件另列。
    

    节点数据状态最近数据年龄CWmin/maxAIFSNHoL msACK %新增HoL样本区间失败NA/断线原因
    

    CW 与算法事件
    cw_requested只表示请求；cw_applied是调用方报告；cw_verified/硬件变化才提供读回证据。全部是观察记录，本页没有写参数功能。跨CW变化区间不分配给任一CW，不据变化前后曲线直接作因果结论。
