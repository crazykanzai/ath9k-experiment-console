`python -m rl_wifi --help` 只有合成离线训练与显式 RTT 账本回放两个命令。

| 文件 | 作用 |
|---|---|
| `rtt.py` | 二进制请求/应用确认协议，完整生成分母、超时/迟到/本地失败、原始事件回放 |
| `probe_transport.py` | 显式传入非阻塞 UDP socket 的节点端收发原语；本次仅假 socket 验证 |
| `spec.py` | 同一观测/动作/奖励契约，两组 CW 的九个动作、K3 映射 |
| `policies.py` | 固定 CW、滑动 UCB、带经验回放和目标网络的 CPU DQN |
| `synthetic.py` | 人工合成 QoS 测试环境，非无线仿真器、非历史数据拟合 |
| `__main__.py` | 有界离线训练、独立种子对照、模型/日志/图/报告输出 |
| `tests/` | 丢失与截止期边界、计数口径、事件回放、TD 目标、状态相关学习等 |

仅借鉴问题设定与 Q 学习思路，未复制作者源码。不是 ReinWiFi 完整复现，未实现其
环境分区、注意力网络、分解 Q 输出、环境近似器或联合限速。
